# Logo del Instituto Tecnológico de Mérida

Este proyecto usa un logo dibujado con widgets (`lib/widgets/logo_tecgram.dart`:
un avión de papel dentro de un círculo azul), no el logo oficial del ITM.

Si el maestro lo permite, se puede poner el logo oficial aquí:

1. Guardar el archivo como `assets/images/logo_itm.png`
2. Registrarlo en `pubspec.yaml`, bajo `flutter > assets`
3. Cambiar `LogoTecGram` por un `Image.asset('assets/images/logo_itm.png')`

No se incluye el logo oficial en el repositorio porque es propiedad del
instituto y no debe distribuirse sin permiso.
