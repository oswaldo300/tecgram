# Animación Rive del oso (login)

El widget `OsoLogin` (`lib/widgets/oso_login.dart`) intenta cargar este archivo:

- `assets/rive/oso_login.riv`

Es el oso clásico de login de Rive (mira al campo activo y se tapa los ojos
al escribir la clave). Para conseguirlo:

1. Entrar a https://rive.app/community y buscar "login teddy" / "teddy bear login"
2. Descargar el archivo `.riv` (hay varios gratuitos de la comunidad)
3. Guardarlo aquí con el nombre `oso_login.riv`
4. La app lo detecta sola al arrancar; si el archivo no está, usa el oso
   dibujado con widgets que ya viene incluido.

Nota: la animación original del oso es de la comunidad de Rive, no es
código de Telegram ni de Cherrygram.
